# Carry

Мод для [Horizon](https://playhorizon.dev) (Minecraft 26.3 на Rust): переносить блоки с содержимым и мирных мобов,
как Java-мод Carry On. Присесть с пустыми руками и нажать правой кнопкой на сундук, печь, бочку или корову — они
исчезают из мира, игрок несёт их перед собой; правый клик по блоку ставит обратно, со всем содержимым.

Правила сервера — `config/craftorio_carry-server.toml` (создаётся при первом запуске): какие блоки и мобов можно
брать, монстры, чужие питомцы, замедление. Сборка и выкладка — в [AGENTS.md](AGENTS.md).
